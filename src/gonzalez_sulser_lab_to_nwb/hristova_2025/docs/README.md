# Hristova 2025 conversion

Documentation of the conversion of the GRIN2B recordings of Hristova et al. (2025) to NWB, for the people who run it.
For the conversion pipeline in general, see the [repository docs](../../../../docs/).

1. [Data organization](data_organization.md): the data share layout, subjects, the recording protocol and the lab files.
2. [Converting sessions](converting_sessions.md): converting sessions, and the output files.
3. [Data streams](data_streams.md): the raw signals and the lab's processed streams, and how they are aligned.
4. [Metadata](metadata.md): editing the metadata files, subject metadata, ontology terms.
5. [NWB file structure](nwb_file_structure.md): what is stored where, and how to read a file.
6. [Spyglass ingestion](spyglass_ingestion.md): ingesting the files into Spyglass.
7. [DANDI staging](dandi_staging.md): validating and uploading the files.
8. [Troubleshooting](troubleshooting.md): conversion errors.
